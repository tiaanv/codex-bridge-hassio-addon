# Codex Bridge (Hassio Add-on)

<p align="center">
  <img src="logo.png" alt="Codex Bridge logo" width="250">
</p>

Run an unmodified, pinned GPTMock repository commit as a Home Assistant add-on,
with an ingress setup page and an authenticated OpenAI/Ollama-compatible
endpoint.

Add-on version `2026.7.13` contains GPTMock release `2026.7.13`.

Home Assistant uses `icon.png` from this add-on folder as the square add-on
icon and `logo.png` as the wider logo artwork.

See [DOCS.md](DOCS.md) for setup instructions and limitations.
